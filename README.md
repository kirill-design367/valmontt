# ВАЛЬМОНТ

Hero-блок сайта-приглашения на вымышленное закрытое событие в альпийском
городке. Грифон — его герб. Только первый экран, без секций ниже.

Кадр снимается на видео и скриншотами, поэтому качество кадра и плавность
важнее функциональности: строго 100 vh, без скролла, всё движение — на
трансформациях и прозрачности.

```bash
npm install
npm run dev            # http://localhost:3000/valmontt
npm run build          # статический экспорт в out/
npm run shoot          # скриншоты 1920×1080, 2560×1440, 390×844 + замер fps
npm run measure        # сверка геометрии кадра с ТЗ
```

## Стек

Next.js 15 (App Router, `output: 'export'`) · TypeScript · Tailwind v4 ·
GSAP + ScrollTrigger · Lenis.

Three.js **не подключён**: в кадре снимок, типографика и тонкие линии —
всё, что тут нужно, отдаёт композитор браузера. WebGL добавил бы контекст,
шейдерные компиляции и риск просадки на записи, не дав ни одного эффекта,
которого нет у CSS и GSAP.

## Что где

| Файл | Зачем |
| --- | --- |
| `components/Hero.tsx` | Разметка кадра: фон → вордмарк → интерфейс → линза и аватарки |
| `components/Hero.module.css` | Вся геометрия и типографика, включая расчёт обрезки вордмарка |
| `lib/motion.ts` | Вход, дыхание линзы, параллакс, `prefers-reduced-motion` |
| `lib/stage.ts` | Координаты глаза грифона → рамка-линза не съезжает при `cover` |
| `app/fonts.ts` | Три кандидата на гарнитуру и обоснования |
| `app/fonts/page.tsx` | `/fonts` — вертикальный вордмарк всеми тремя в финальном кегле |
| `scripts/audit-fonts.py` | Проверка кириллицы по таблице cmap в самом файле шрифта |
| `scripts/generate-placeholder-art.py` | Генератор временных подложек |

## Ассеты

`public/valmont-desktop.jpg` (16:9) и `public/valmont-mobile.jpg` (9:16).

**Сейчас там сгенерированные заглушки.** Настоящие снимки грифона кладутся
поверх с теми же именами — больше ничего менять не нужно, при одном условии:
глаз должен остаться в тех же нормализованных координатах, потому что к ним
привязана рамка-линза.

```
десктоп 16:9  — (0.587, 0.238)
мобайл  9:16  — (0.505, 0.232)
```

Если в финальных снимках глаз в другом месте — поправьте `EYE` в
`lib/stage.ts`, и рамка снова сядет ровно на него на любом соотношении сторон.

## Публикация

GitHub Pages из Actions, `.github/workflows/deploy-pages.yml`. Обязательные
условия зашиты в `next.config.ts` (`output: 'export'`,
`images.unoptimized`, `basePath` и `assetPrefix` = `/valmontt`) и в
workflow (`.nojekyll` в корне выдачи + проверка путей перед публикацией).

## Правки, которые попросят первыми

- **Гарнитура.** `app/fonts.ts` → в `globals.css` токен `--font-display`.
- **Разбивка заголовка.** `HEADLINE` в `components/Hero.tsx`.
- **Размер и обрезка вордмарка.** `--wordmark-size` и `--wordmark-track`
  в `app/globals.css`; столбец считается как `8 × (0.728em + трекинг)`.
- **Акцент.** `--color-crimson` — единственное цветное пятно в интерфейсе.
